# 📝 Project Overview

This project is my personal portfolio website developed using React and Vite. It highlights my education, technical skills, projects, and contact information in a clean and modern user interface. The portfolio is fully responsive and designed to provide visitors with an overview of my work and learning journey.

Repository language composition (approx.):

- JavaScript
- CSS
- HTML

# ✨ Features

- Responsive modern UI
- Hero section with introduction
- About Me section
- Skills showcase
- Education timeline

- Contact form using EmailJS

# 🚀 Getting Started

## Installation

```bash
# Clone repository
git clone https://github.com/bishalbudhathoki004/portfolio.git

# Open project
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open:

```
http://localhost:5173
```
